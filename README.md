This is a collection of small Python projects created while practicing programming and probability. The main idea is to understand the logic behind common probability questions better, while prcaticing programming

# Current Projects

1. Dice roll simulation
Let's you pick the amount of sides of a dice, as well as the number of rolls you want to make. Very well shows how the mean of the observed rolls converges to the teoretical mean, when performed many times.
